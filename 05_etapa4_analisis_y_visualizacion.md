# 05. Etapa 4 – Análisis y Visualización de Datos

Este documento aborda la cuarta etapa del ciclo de vida de los datos: **análisis y visualización**. Se analizan las herramientas para consultas SQL interactivas y ad-hoc, plataformas de Data Warehousing, inteligencia de negocios (BI) con analítica generativa, y el espectro de opciones de Inteligencia Artificial / Machine Learning en AWS (desde servicios administrados API-first hasta IA Generativa con Amazon Bedrock y desarrollo a medida con Amazon SageMaker).
